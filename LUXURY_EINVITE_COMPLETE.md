## User Flow

### Creating an Invitation:

1. **Choose Template**
   - Browse 5 luxury templates
   - Tap to select
   - Opens editor automatically

2. **Customize Details**
   - Enter bride & groom names
   - Add family details
   - Select event type
   - Set date & time
   - Add venue information
   - Upload couple photo (optional)
   - Choose quote or verse

3. **Preview**
   - Tap preview button
   - See full-screen invitation
   - All details rendered beautifully
   - Interactive buttons available

4. **Share**
   - Add to calendar
   - Open maps for venue
   - Share via WhatsApp, Instagram, etc.
   - Flip card for 3D effect
